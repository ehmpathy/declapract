## defects repaired (prior stone)

### defect 1: src cycle in FileCheckDeclarationInput

- **what**: dpdm detected circular dependency in src/domain.objects/
- **how**: `git diff origin/main -- src/domain.objects/FileCheckDeclarationInput.ts` showed import from barrel `./`
- **why**: barrel re-exports FileCheckDeclarationInput, which creates a cycle
- **fix**: changed to direct import `./FileCheckDeclaration`

### defect 2: zod 4.x api change

- **what**: type error on `z.record()` calls
- **how**: `git diff origin/main -- package.json` showed joi → zod 4.3.4
- **why**: zod 4.x changed api to require key type as first argument
- **fix**: added `z.string()` as first argument to all `z.record()` calls

### defect 3: semver four-part version

- **what**: `valid('1.2.3.4')` returned `'1.2.3'` instead of `null`
- **how**: `git diff origin/main -- check.minVersion.ts` showed new regex
- **why**: regex was not anchored at end (`$`)
- **fix**: added `$` anchor to regex

### defect 4: semver prerelease comparison

- **what**: `gte('1.0.0', '1.0.0-beta.1')` returned `true` incorrectly
- **how**: same file as above
- **why**: `valid()` dropped prerelease info from return value
- **fix**: kept prerelease in return: `parsed.prerelease ? \`\${base}-\${parsed.prerelease}\` : base`

### defect 5: test asset paths

- **what**: integration tests failed — expected files at "bad" locations
- **how**: `git diff origin/main -- .test.assets/` showed renamed directories
- **why**: declapract applied fixes to fixtures meant to be "bad"
- **fix**: restored original paths via mvsafe
