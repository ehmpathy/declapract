# 3.2.reflect.test.defects

## defect classifications

### defect 1: src cycle in FileCheckDeclarationInput

**classification**: repo quirk

**rationale**: this repo had a barrel import in `src/domain.objects/` that created a cycle. this is specific to this repo's structure and does not indicate a practice bug. other repos should avoid barrel imports.

### defect 2: zod 4.x api change

**classification**: practice bug

**rationale**: the declapract-typescript-ehmpathy practice introduced zod 4.x which changed the `z.record()` api. repos with custom zod schemas will encounter this. the practice should document this api change.

**citation**: the practice declares zod in package.json but does not mention the api change.

### defect 3: semver four-part version

**classification**: practice bug

**rationale**: the inline semver implementation in declapract-typescript-ehmpathy has a regex bug. the `valid()` function's regex is not anchored at end, so `1.2.3.4` matches as `1.2.3`. this affects any repo that uses minVersion checks.

**citation**: the practice provides the check.minVersion.ts template with this bug.

### defect 4: semver prerelease comparison

**classification**: practice bug

**rationale**: the inline semver implementation drops prerelease info in `valid()`, so prerelease comparison fails. this affects repos that use minVersion checks with prerelease versions.

**citation**: same file as defect 3.

### defect 5: test asset paths

**classification**: repo quirk

**rationale**: this repo has test fixtures intentionally at "bad" locations to test failure cases. declapract "fixed" them. this is specific to declapract's own test suite — other repos won't have fixtures meant to fail.
