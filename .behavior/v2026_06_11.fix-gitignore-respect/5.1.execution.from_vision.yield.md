## peer review OOM diagnosis

at verification phase, discovered that peer reviews (via `rhx review --repo bhrain`) also OOM at ~4GB. this is a separate issue in `rhachet-roles-bhrain` package.

### root cause

`enumFilesFromGlob` in `rhachet-roles-bhrain` uses `fast-glob` but does not exclude common gitignored directories. when `--paths-with '**/*.ts'` is passed, fast-glob enumerates ALL TypeScript files with node_modules (~100k+ files).

### location

```
rhachet-roles-bhrain/src/domain.operations/review/enumFilesFromGlob.ts
```

### fix

added default ignore patterns:

```typescript
const defaultIgnores = [
  '**/node_modules/**',
  '**/.git/**',
  '**/dist/**',
  '**/build/**',
  '**/coverage/**',
  '**/.next/**',
  '**/.nuxt/**',
];
const allIgnores = [...negativePatterns, ...defaultIgnores];
```

### verification

- before: OOM at ~4GB after enumFilesFromPaths
- after: review completed in ~35 seconds with 3 target files

### next steps

this fix was applied to node_modules for diagnosis. needs upstream to rhachet-roles-bhrain source repo and publish.
