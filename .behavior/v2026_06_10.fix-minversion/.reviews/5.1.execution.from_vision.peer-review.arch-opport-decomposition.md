# blocker.1: Multiple operations in one file violates single responsibility

**rule**: .agent/repo=bhuild/role=behaver/briefs/practices/behavior.execution/architect/rule.prefer.decomposable-architecture.md

**locations**:
- src/domain.operations/declaration/readPracticeDeclarations/readPracticeDeclaration/getFileCheckDeclaration/checkExpressions/check.minVersion.ts

The file exports six distinct operations (isLinkedDependencyVersion, regex constants, getMinVersionFromCheckMinVersionExpression, hasIfInstalledModifier, isCheckMinVersionExpression, checkDoesFoundValuePassesMinVersionCheck) instead of one operation per file. This prevents decomposable architecture where each operation has clear grain (transformer/communicator/orchestrator), explicit inputs/outputs, and can be recomposed independently. # blocker.2: Complex transformer mixes concerns without decomposition

**rule**: .agent/repo=bhuild/role=behaver/briefs/practices/behavior.execution/architect/rule.prefer.decomposable-architecture.md

**locations**:
- src/domain.operations/declaration/readPracticeDeclarations/readPracticeDeclaration/getFileCheckDeclaration/fixMethods/fixContainsJSONByReplacingAndAddingKeyValues.ts

deepReplaceOrAddCurrentKeyValuesWithDesiredKeyValues is a single transformer that handles key merging, absent-value logic, array special cases, minVersion check evaluation, ifInstalled filtering, and recursion. This lacks single responsibility and grain clarity (should decompose into smaller named transformers like handleMinVersionReplacement or getNewValueForKey). Complex inline IIFE if-chain requires mental simulation and hinders recomposition.

**snippet**:
```ts
const newValue = (() => {
  if (currentValue === undefined || currentValue === null) {
    if (
      typeof desiredValue === 'string' &&
      hasIfInstalledModifier(desiredValue)
    )
      return undefined;
    return desiredValue;
  }
  if (desiredValue === undefined) return currentValue;
  if (Array.isArray(desiredValue)) return desiredValue;
  if (isCheckMinVersionExpression(desiredValue)) {
    const minVersion =
      getMinVersionFromCheckMinVersionExpression(desiredValue);
    if (!minVersion)
      throw new UnexpectedCodePathError(
        "checked that its a min version expression but couldn't extract a min version",
      );
    const ifInstalled = hasIfInstalledModifier(desiredValue);
    const passesMinVersion = checkDoesFoundValuePassesMinVersionCheck({
      foundValue: currentValue,
      minVersion,
      ifInstalled,
    });
    if (passesMinVersion) return currentValue;
    return minVersion;
  }
  if (typeof desiredValue !== 'object') return desiredValue;
  if (desiredValue === null) return desiredValue;
  return deepReplaceOrAddCurrentKeyValuesWithDesiredKeyValues({
    currentObject: currentValue,
    desiredObject: desiredValue,
  });
})();
```
