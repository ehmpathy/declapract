wish =

add `.ifInstalled()` modifier for version checks

## problem

when a dependency should be at a minimum version *if installed*, there is no clean way to express this in best-practice.

`optional: true` only skips when the *file* does not exist, not when the *dependency* is absent from an extant package.json.

## current workaround

create a bad-practice with custom FileCheckFunction — works but verbose.

## proposed solution

add `.ifInstalled()` modifier to version checks:

```js
{
  dependencies: {
    'with-simple-cache': @declapract{check.minVersion('0.16.2').ifInstalled()}
  }
}
```

## semantics

- package not installed → pass (skip)
- package installed >= x.y.z → pass
- package installed < x.y.z → fail

## why fluent chain

composable pattern enables future modifiers:
- `check.minVersion('1.0.0').ifInstalled()`
- `check.minVersion('1.0.0').warnOnly()`

## use case

auto-bump optional packages (e.g., cache libraries) that should be current if present, but aren't required for all projects.
